# 职员转会与职务调整

“查找职员”的职务筛选默认不限属性，已核对身份和合同的人员可被找到，包括部分没有完整属性资料的队医。双击搜索结果打开职员页，再点击“转会／职务…”。目标可按俱乐部全名、简称或 UID 搜索，已核对球队归属的补丁俱乐部也会列出。

选择“保留原职务”或到任职务，点击“预览…”核对原俱乐部、目标俱乐部和职务，确认后提交。原俱乐部也可作为目标。旧版只改了职务文字而部门不同步时，可以在原俱乐部明确重选当前职务，核对预览后应用。

| 类别 | 支持的职务 |
| --- | --- |
| 教练与分析 | 教练、助理教练、门将教练、体能教练、定位球教练、青训主管、表现分析师、首席表现分析师 |
| 医疗与运动科学 | 理疗师、首席理疗师、队医、首席队医、运动科学家、运动科学主管 |
| 球探与招募 | 球探、首席球探、招募分析师、租借主管、技术总监 |
| 专属岗位 | 主教练、足球总监 |

跨俱乐部转会的合同归属调整至新俱乐部一线队，本队普通改职沿用当前球队。完整合同与简式合同使用各自的识别方式，保留原工资和已有期限。已通过核对的更改支持在“变更记录”整组撤销。FM 中可在新俱乐部的职员名单查看，必要时推进一天。

功能适用于已有俱乐部合同、身份与归属均可核对的普通职员。目标部门使用现有名单空间，满员或名单尚无空间时会提示。专属岗位须空缺，新任命会用本次载入的其他同类职员记录核对该岗位。玩家本人、董事会职务和球员兼职员由各自的游戏流程处理。

## 结构核对

已用本机 Steam 27.1.0+2505117 的引擎文件只读核对 `FULL_CONTRACT`、`BASIC_CONTRACT` 和 `ACTUAL_NON_PLAYER`。简式合同长度为 0x28，职位字段为一字节。转会只修改职位、球队归属、涉及的部门名单和专属岗位。预览读取的身份和名单在提交前复核，写入后逐项回读。离线验证和实机范围见 [VALIDATION.md](../VALIDATION.md)。

职位编码、俱乐部部门和专属岗位参考了 FM27 的公开实测记录。 [FMLibreEditor 的职员结构记录](https://github.com/tozmoz/FMLibreEditor/blob/53498c489ac25ae65ed96e82f68e95aa1cf4744f/docs/recon/fm27-staff.md)

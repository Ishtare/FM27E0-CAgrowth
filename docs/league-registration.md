## 按实际赛事读取

在报名规则窗口搜索英超、西甲、德甲、法甲、意甲、赛事原名或 UID，选择本次扫描取得的赛事。只显示实际存在、类型和条件已识别的规则；联赛补丁或新赛季可能改变这些资料。

总名单、非欧／外援上限、本国籍、本国培养及俱乐部培养要求分别处理。最低培养要求可能表现为保留名额，俱乐部培养也可能是本国培养的子集，不能重复相加。非本土名额按兼容的实际总人数与培养保留位计算，不把某个联赛的数值写死。

带附加条件、重复或不一致的规则只读显示。未发现某种通用人数规则，不能推断该联赛没有其他限制。已转入球员的历史意大利非欧认定继续使用个人修复入口。

## 如何放宽

选择实际赛事及一项规则，修改目标值并检查预览，再点击应用。规则写入影响该赛事所有球队；检测到共享同一数据的赛事时会一并列出，不是只针对当前球员豁免。

- 上限：调高人数。外援、非欧、非本土培养的上限设为 0 表示零名额；快捷放宽填入 1000 人，并非删除全部规则。
- 最低要求：调低人数，0 表示不再要求这一类人数。最低要求不会被误当成最高人数。
- 总报名容量：接受 1–1000 的明确正整数，不写入意义未核实的 0 或负数；也不会因此更改 U21 豁免。

快捷按钮只填写预览，不会立即写入。应用前再次核对当前日期、赛事身份、条件、方向和各份数据，写入后读回。失败时尝试恢复本次已确认的改动；当前会话内、同游戏日且资料未变化时可成组撤销。

## 支持的规则表示

| 编码 | 类型 | 方向 |
| --- | --- | --- |
| `0x02 / 0x03 / 0x04` | 外援首发／替补席／比赛名单 | 最大人数 |
| `0x05 / 0x06 / 0x07` | 非欧首发／替补席／比赛名单 | 最大人数 |
| `0x09` | 报名名单总人数 | 最大人数 |
| `0x12 / 0x15` | 非欧／外援注册名单 | 最大人数 |
| `0x1E` | 每赛季从国外引进非欧球员 | 最大人数 |
| `0x67` | 非本土培养球员名单 | 最大人数 |
| `0x0B / 0x26 / 0x27` | 原有俱乐部／本国培养类型 | 最低人数 |
| `0x91 / 0x92 / 0xFD` | 0–21 岁阶段培养：俱乐部／本国／两者之一 | 最低人数 |
| `0xD4` | 本国籍球员 | 最低人数 |

共 18 类，只有实际存在的类型才会出现在选择框。保留规则类型、方向和所有附加条件，仅修改已核实的数值。最大值方向为 `+0x1E` 的单字节 255，最低值为 1，后一个字节仍是独立元数据。要求主运行值及两份保存表示都存在、地址不同、数值相等，才生成三处修改。重复、带条件或不一致时只读。

赛事来自已扫描球队及奖金表中实际可验证的对象；姓名缩写和 UID 仅用于搜索，不用于决定规则或白名单。来源格式和许可见 [实现依据](registration-evidence.md)。

## 现实规则参考与游戏规则的区别

英超官方 2026/27 说明将非本土培养上限 17、总名单 25 与 U21 名单分开，并说明培养身份不取决于国籍。本版从存档的总人数与培养保留位计算展示相应差额，不把 17 写死。[英超官方说明](https://www.premierleague.com/en/news/4706140/)

德国官方分别说明德国籍球员合同要求和本土培养要求。这支持将国籍与培养分开显示，不是把德甲套成意甲式的非欧年度引援配额。[德国籍球员要求](https://www.bundesliga.com/en/bundesliga/news/changes-to-loan-player-regulations-germany-35065)，[本土培养规则](https://www.bundesliga.com/en/bundesliga/news/dfl-honours-home-grown-debutants-youth-academy-development-35590)

西班牙足协 2025/26 第 22 条列出 25 人总名单与非欧名额；法国 LFP 2024/25 章程第 552–553 条区分非欧限额与协议国家，并为法乙列出特殊条件。这里保留文件赛季，作为概念参考，不能代替当前游戏读取。[RFEF 原文](https://rfef.es/sites/default/files/pdf/circulares/98_con_anexos_20250624.pdf)，[LFP 原文](https://www.lfp.fr/assets/24_25_LFP_CHARTE_FOOTBALL_PRO_10_09_30423088ad.pdf)

## 验证范围

本地检查覆盖 18 类规则、最高与最低方向、总容量范围、三份数值一致性、部分失败回退、撤销、非本土差额、条件分支只读及独立入口。生产代码只读核对过不同联赛的修改预览，没有由开发工具应用。

个人非欧修复及规则编辑已有使用反馈，但比赛资格、保存重载和不同联赛补丁组合仍需分别验证。仅适配核实的 Steam 27.0.1+2503222，其他版本继续只读。

工作许可不是名单人数规则。许可表涉及记录、排序索引、人物标记及未经本项目验证的游戏内存分配，本版没有加入该注入分配方式。U21 条件、欧战名单和特殊资格仍分别处理，提高国内名额不自动解除这些限制。[FA 工作许可／GBE 资料](https://www.thefa.com/football-rules-governance/policies/player-registration/points-based-system)

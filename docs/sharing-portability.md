# 分享与姓名库

## 运行所需文件

v1.1.32 的 EXE 内置完整姓名资料及显示规则。

- 5,270 条有来源的人物对照。
- 506,169 条姓名组成记录。
- 91,482 条完整／条件记录，以及 251 个地区语言条目。

本版内置词库的 SHA-256 与上一版一致。姓名资料从 EXE 的嵌入资源加载，运行不依赖作者的工作目录、另一个聊天的文件夹、外部姓名插件或联网下载。

独立目录中只保留 EXE 的验证通过：完整词库载入、已收录人物及青年姓名的中文显示、中英文搜索均通过。此检查没有启动程序窗口、读取游戏进程或修改游戏。

程序可以额外读取自身目录下 names 文件夹中的可选对照及身份缓存；它们不属于内置词库依赖。分享包不含个人导入与缓存。

读取原版数据库或早期存档使用包内 third-party/libzstd.dll。分发或运行时保留整个 third-party 文件夹，内有依赖及许可。数据库默认值由各自电脑的 FM27 安装目录提供。

## 分享内容

直接分享整理好的完整版 ZIP。包中含程序、公开说明、许可证、校验清单及“对应源码”中的完整源码 ZIP。源码包含词库与离线构建工具，便于维护，不需要解压源码才能运行程序。

包中不含私人存档、个人设置、修改日志、用户姓名缓存或私人测试附件。请勿把已经使用过的程序文件夹重新压缩，避免带入运行后生成的个人文件。

姓名库的可移植性不代表所有游戏构建都兼容。接收者仍需使用 Windows、兼容的 FM27 构建并载入自己的存档；具体编辑功能按本次检查启用。自动组合及音译保留相应标识，不保证每项都是官方译名。

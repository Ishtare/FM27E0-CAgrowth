# 统一报名与资格管理及国家范围

v1.1.20 已补充经完整版本、映像和原生代码核对的 Steam 27.1.0+2505117 适配，并保留旧构建及逐对象检查。新构建的只读连接已核对，实际应用与保存重载仍需分别验证，见 [27.1 适配](engine-27.1.md)。

v1.1.17。主入口为“赛事与报名 → 报名与资格”，球员“更多操作”的报名入口及独立窗口使用同一界面。

| 层级 | 可做什么 | 范围与边界 |
| --- | --- | --- |
| 球员国内／欧战登记 | 根据当前球队记录补齐登记或清理取消登记 | 共用关系结构，意、西、法、德、英及其他国家都按实际对象检查；不会获得其他资格 |
| 球员当季历史非欧认定 | 清除已经核实的独立标记 | 当前仅核实意大利。其他国家明确只读，不使用意大利偏移套写 |
| 赛事名额与培养 | 已识别的非欧／外援上限、非本土培养上限、总人数及最低要求 | 对整项赛事生效，可能共享；带条件、重复或不一致规则只读 |

意大利历史非欧状态来自已核实的专用标志。公开参考项目的字段也只明确列出意大利认定，通用登记结构不包含一个可直接当作各国历史非欧开关的字段。因此没有据联赛名称猜测相邻标记。西甲、法甲等的常规人数限制可在赛事页处理；若仍被个人状态阻止，需要对应案例和结构核对后再扩展。

修改主／第二国籍不等于重新判定历史引援资格，也不等于本土培养或工作许可。相同地，修复登记记录不保证满足人数、特殊资格或比赛名单要求。界面分开显示作用范围，并给出只读原因和预览。

仅适配已核实的 Steam 27.0.1+2503222 和原生／对象检查。保留未知版本、外租、兼教练与临时球队限制；多项写入仍检查身份、合同、日期、旧值，回读、回滚与成组撤销。

意大利个案此前有可注册的用户反馈，联赛规则此前有可查看和修改的反馈。本轮国家通用登记通过意、西、法、德、英及未知国家的人工副本测试，未做其他国家真实存档修复，不把这类检查当成全部联赛实测成功。

来源及原生结构见 [实现依据](registration-evidence.md)；规则类型、人数方向见 [联赛规则](league-registration.md)。参考 [FMRTE 个人资料](https://docs.fmrte.com/players/personal-details/)、[登记与许可](https://docs.fmrte.com/players/registration-and-permits/)，以及上述实现依据内固定版本的公开源码。

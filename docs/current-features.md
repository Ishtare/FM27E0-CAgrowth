# 五类功能补齐与验证

v1.1.20 已补充经完整版本、映像和原生代码核对的 Steam 27.1.0+2505117 适配，并保留旧构建及逐对象检查。新构建的只读连接已核对，实际应用与保存重载仍需分别验证，见 [27.1 适配](engine-27.1.md)。

v1.1.15，2026-11-15。针对通过原生签名及映像核对的 Steam 27.0.1+2503222。此次补齐实际读写、冻结和撤销路径；不是只改提示或取消检查。其他构建不套用这套布局。

## 实现

- **体能、比赛状态与士气**：前两项使用两字节整数；士气使用 0–20 的单字节字段，界面仍按百分比显示。读取、应用和冻结共用编码规则，士气修改不触及相邻字节。
- **伤病**：改用核实后的医疗资料入口，核对球员身份、伤病指针列表、类型及完整记录。治疗仅缩短列表结束位置，保留记录和容量；持有者或记录变化时停止，允许在数据仍有效时撤销。
- **疲劳度**：保留有符号两字节读写，当前构建恢复值为 0。可在位置／状态表编辑，修改及撤销核对人物身份。
- **球衣号码**：分别解析本队合同与借入合同，同俱乐部一线队／预备队按俱乐部归属核对。空借入容器不当成有效合同，也不再让它使其他球员全部只读。有效号码为 1–99，255 表示未设置；无法核对的个别球员继续拒绝写入。
- **票价与季票**：游戏中的票价 -1 表示未设置，界面显示“未设置”。可以设置新票价，保留货币换算。资料、财务对象及旧值核对后批量应用，失败回滚，撤销可恢复未设置状态。保持原范围，不用扩大范围绕过校验。

新增写入通过预览读集、归属检查、旧值比较、回读和回滚，并写入原有变更记录。已知限制和新异常分开显示，尚未适配原因中文化；核心失败及新的非核心异常仍提示。

## 生产代码只读验证

运行同一份生产扫描和检查，进程权限 0x410，无写入权限、无游戏窗口操作。

| 检查 | 结果 |
|---|---|
| 引擎 | Steam 27.0.1+2503222，原生布局校验通过 |
| 名单 | 已核对人物及完整财务对象，不公开私人存档的名单或统计 |
| 扫描禁用项目 | 无；五类功能的整体检查全部通过 |
| 体能／状态／士气 | 三种字段的读取副本修改验证通过，士气相邻字节保留 |
| 疲劳度 | 有符号两字节副本修改通过 |
| 治疗 | 当前伤病列表的副本移除通过，原记录保留 |
| 号码 | 本队及租借号码的副本修改通过 |
| 票价／季票 | 未设置票价与季票数量的副本修改通过 |
| 真实游戏数据 | 未由开发工具写入，原数据核对未变化 |

整体检查通过不等于每个独立对象一定可编辑。扫描中的少量合同归属异常仍由单人预览拒绝；没有降低原有检查比例，也不把不存在的合同当作有效资料。

12,747 项本地断言通过，新增状态编码／相邻字节保护、冻结值格式、医疗持有者及伤病类型、治疗撤销、合同归属、预备队及空租借容器、租借号码、未设置票价、批量失败回滚、过期归属拒绝及提示分类检查。

副本模拟只覆盖返回的字节数据，不调用游戏写入。五类功能已有界面与编辑入口正常的反馈，实际应用、推进日期及保存重载仍待验证。

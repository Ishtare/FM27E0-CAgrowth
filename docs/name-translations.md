# 姓名词库与自动补全

姓名显示使用有来源的人物对照、完整姓名词库与有标识的自动补全。处理范围包括已扫描球员与职员；这里只说明公共资料和显示规则。

## 来源与处理顺序

1. 原有 5,270 条有来源的人物对应，包含央视、新华社与既有官方中文资料；用户导入的可靠来源对照也保留身份检查。
2. 同项目 FMPersonChinese 0.2.0 的游戏姓名资料：506,169 条组成记录、91,482 条完整／条件记录、251 个地区语言条目。完整词条需符合原名、地区和适用身份条件；组成词条区分名字、姓氏、常用名，并在地区、语言及全局唯一候选之间核对歧义。
3. 词条缺失的部分使用同工程的纯托管文字／读音规则。它会推断语言并处理新组合及多种文字，全部近似结果明确标识，不声称是官方译名。

词条组合不等同于已核实的完整人物译名。数字统计按记录而非去重人物计算；506,169 不是 506,169 名球员。地区只是一种语言来源近似，国籍更改、多语言国家和迁移经历可能影响读音选择。拼音、日文或韩文转写也不能保证恢复原本汉字。

对外界面标记：〔词库〕、〔组合〕、〔音译〕。有来源人物对照继续优先。字母缩写优先改用同一人物资料中已有的完整中文候选；缩写加入别名保留搜索。无完整候选时，可用词库／音译补齐，并显示相应来源。

## 接入范围

普通球员和球员兼职员的扫描读取实际名字、姓氏、常用名及原始检索串；职员与经理复用同一显示规则。中文、英文和 UID 搜索保持，首字母或同名不会借用别人的已确认人物身份。已归一化的检索串会缓存，原名、中文或别名变化时失效；不会在每次输入时反复完成整套音译。

自动结果不写入游戏姓名、存档或游戏插件目录，也不作为年龄修改后的已核对 UID 绑定保存。本版未引入原工程的游戏搜索钩子、原生翻译桥接、原生音译库、后台服务或在线请求。

## 完整资料及源码

`name-data/name-bank.gz` 是无损组合快照，编译后嵌入 `FM27E0.name-bank.gz`。运行时无需旁置资料。`tools/unpack_name_bank.py 输出目录` 可以离线还原 countries.tsv、words.tsv、contexts.tsv；还原字节与原资料的 BOM、换行及 SHA-256 一致。散列和计数见 `name-data/fallback-manifest.json`。

`NameFallbackDictionary.cs` 与 `NamePhonetics.cs` 改编自同项目用户姓名工程，原作者说明见 `NAME-FALLBACK-NOTICE.txt`。用户工程作者代码按 GPL-3.0-or-later 提供，本改版保留该许可与原 FM27€0 的署名及附加条款。游戏姓名／翻译资料保持原权利归属，不因作者代码使用 GPL 而重新获得 GPL 许可；来源说明保留，不把它描述成另一个作者独立创作的数据库。发行不含游戏 DLL、原始元数据文件或私人存档。

## 验证与边界

本地检查覆盖完整词库载入、青年姓名、中文／英文／UID 查询、已确认译名优先、字母缩写、名字与姓氏区别、常用名优先、原有中文、无效姓名、语言不确定性、多种文字、未见组合、缓存失效及职员显示。

词库无损还原及姓名目录重新生成检查通过。姓名与双语搜索已有正常使用反馈，但自动组合或音译不能保证每个候选均为官方译名，也不能据此推断任意存档或未来赛季的准确率。

转换只形成修改器中的中文候选，不写入游戏姓名。完整版与对应源码均保留完整词库及许可说明；不需要另装姓名插件。
